Heidi Workspace Access

Heidi Workspace Access is a private, single-user personal assistant tool. It connects one individual's own Google account (Gmail, Calendar, Drive, Docs, Sheets and Contacts) to software running on that individual's own computer, so the owner can search, read and draft their own email and documents.

It is not offered to the public, has no other users, and is not a commercial product.
